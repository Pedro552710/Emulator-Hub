# Eigene Grafiken

`logo.svg` wurde eigens für Emulator Hub als einfaches generisches Controller-Symbol in einem abgerundeten Quadrat erstellt. Es enthält geometrische Formen ohne eingebundene Bilder, Schriften, externe Ressourcen oder Markenlogos. `logo.png` und `icon.ico` sind mit `tools/make_icons.py` daraus erzeugte Ableitungen. Diese eigenen Projektgrafiken werden unter der [MIT-Lizenz](../LICENSE) des Projekts bereitgestellt.

Weitere Bilder liegen hier nicht. Cover aus IGDB/ScreenScraper gehören in den lokalen, von Git ausgeschlossenen Cache. Sie stehen unter den Rechten und Bedingungen ihrer Anbieter und werden nicht durch die Projektlizenz freigegeben. Für ausgetauschte Logos musst du selbst die nötigen Nutzungsrechte besitzen; fremde Markenlogos oder Spielfiguren werden nicht mitgeliefert.
